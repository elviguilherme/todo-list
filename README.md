# Gerenciador de Tarefas (To-Do)

Aplicação web para organizar tarefas com prioridade, feita com HTML, CSS e JavaScript puro, sem frameworks.

Trabalho da disciplina de Front-end (FWII) do curso Técnico em Desenvolvimento de Sistemas – IFTM Campus Uberaba Parque Tecnológico.

## Funcionalidades

- Adicionar tarefas com descrição e prioridade (Baixa, Média ou Alta)
- Validação dos campos com mensagens de erro específicas
- Cores diferentes para cada nível de prioridade
- Marcar tarefas como concluídas
- Excluir tarefas com janela (modal) de confirmação

## Tecnologias

- HTML5
- CSS3
- JavaScript (manipulação do DOM e eventos)

## Como executar

Baixe o repositório e abra o arquivo `index.html` no navegador.
